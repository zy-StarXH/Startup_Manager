# Startup Manager v1.1.2

修复启动项图标周围出现黑底、黑边的问题。

- 保留 Windows Shell 图标的透明像素和半透明边缘，修复 HBITMAP 转 PNG 时丢失透明通道的问题。
- 移除真实图标容器额外的阴影和圆角裁剪，完整显示原有图标；图标自身的黑色图案保留。
- 继续支持旧式图标的透明掩码，以及无法提取图标时的字母占位。
- 统一主程序、提权助手、侧栏和设置页版本为 1.1.2。

验证：Release 构建成功，215 项测试通过、1 项因非管理员无法创建临时计划任务而跳过。
发布版真实界面通过启动项、服务项、计划任务的图标像素与样式检查，截图已人工核验。

下载 `StartupManager-win-x64-v1.1.2.zip`，解压后运行 `StartupManager.exe`。
需要 Windows 11 x64 和 WebView2 Runtime；无需另外安装 .NET。
同时提供 SHA-256 校验文件。
