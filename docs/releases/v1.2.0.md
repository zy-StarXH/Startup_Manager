# Startup Manager v1.2.0

新增受保护启动项的逐项管理功能。

- 系统启动项、Microsoft 计划任务、服务和驱动相关项等默认保持工具保护；现在可在详情中点击“允许管理…”，确认后解锁。
- 确认窗口展示原保护原因。解锁决定持久保存，仅作用于选中的项目，不会立即改变启动状态。
- 详情提供“恢复工具保护”；重新锁定不会还原启动状态，需要还原配置时可使用恢复中心。
- 已关闭、只通过备份显示的项目也保持一致的解锁/锁定状态。
- 后端重新扫描并校验解锁请求；实际修改继续执行管理员权限检查、备份、验证和失败回滚。
- Windows 策略限制和安全检查失败保持只读；不会通过修改 ACL、所有者或组策略强制执行被系统拒绝的操作。
- 保留 v1.1.2 的原始图标透明度与无黑边显示。

本功能由用户判断项目用途，不会自动把系统组件判为广告或无用项。

验证：Release 构建成功，225 项测试通过、1 项权限相关跳过；30 项保护界面检查及图标回归通过。
真实系统项只验证确认与取消，修改流程使用模拟对象；没有修改真实系统服务。

下载 `StartupManager-win-x64-v1.2.0.zip`，解压后运行 `StartupManager.exe`。
需要 Windows 11 x64 和 WebView2 Runtime；无需另装 .NET。附 SHA-256 校验文件。
